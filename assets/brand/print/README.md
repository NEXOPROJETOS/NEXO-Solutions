# Logo NEXO — arquivos para impressão

Todos os arquivos são SVG vetoriais com fundo transparente e sem imagens raster. As dimensões físicas estão declaradas no próprio arquivo; imprima em escala de **100% / tamanho real** para obter a medida indicada.

- `nexo-horizontal-cor-260x75mm.svg`: assinatura completa em cores, adequada para costas e materiais horizontais.
- `nexo-horizontal-monocromatico-260x75mm.svg`: versão de uma cor para silk, recorte ou aplicação econômica.
- `nexo-horizontal-branco-260x75mm.svg`: versão branca para tecido ou fundo escuro.
- `nexo-peito-cor-100x28mm.svg`: assinatura compacta para peito.
- `nexo-simbolo-cor-100x100mm.svg`: símbolo N isolado para etiquetas, mangas e aplicações quadradas.

As letras foram desenhadas como vetores, sem dependência de fontes instaladas. Para bordado, confirme com o fornecedor a conversão para o formato de máquina e a espessura mínima de traço.
